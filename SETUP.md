# Setup

1. Create a public GitHub repository named exactly `jonam17`.
2. Copy this package into the repository root.
3. Commit and push to the `main` branch.
4. Open **Actions** and run **Generate contribution snake** once manually.
5. After the workflow creates the `output` branch, the contribution snake will appear in the README.

## Notes

- GitHub profile READMEs render supported SVG animation, but they are not full interactive web pages.
- The custom project cards are intentionally self-contained SVG files with no external fonts or scripts.
- Edit text directly inside each SVG to change project labels.
- The telemetry cards rely on third-party README image services and may occasionally be rate-limited.
